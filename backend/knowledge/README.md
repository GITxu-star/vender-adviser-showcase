# knowledge/（展示版为空）

本目录在原项目中存放 RAG 语料，展示版不包含具体内容，仅保留结构说明。

```
knowledge/
├─ 案例库/     20 个真实摊位案例（每个案例含：改了哪四件事 / 结果数字 / 成本与退路 / 避坑点）
├─ 百科/       经营常识：点位流量、竞争演化、政策红利、让顾客停 3 秒等
└─ 法规/       摆摊时间与地点的地方性规定整理
```

每个案例的格式（脱敏示例）：

```markdown
# 案例：夜间烤红薯摊

- 场景：三线城市夜市，固定摊位，单价 6-10 元，日销 60 份左右
- 原状态：商品放在地上，没有价格牌，路人看不清卖什么
- 改动（4 件）：
  1. 纸板手写价格牌，立在摊位正前方
  2. 商品抬高到 60cm，形成前后两排
  3. 加一盏暖光灯照向商品
  4. 招牌只写「现烤红薯」四个大字
- 成本：约 35 元，2 小时内可完成
- 结果：停下看的人从每天约 10 人增加到 25 人，日销 60 → 82 份
- 退路：全部可撤，纸板与灯可复用
- 避坑：灯不要直射顾客眼睛；价格牌字高至少 15cm
```

完整语料与知识图谱数据为作者私有资产，不随本仓库分发。检索与推理代码见 `backend/rag.py`、`backend/pipeline.py`、`backend/rules.py`。
